#+TITLE: looking-glass: optic laws and documented deviations

This file records the laws each optic kind is expected to satisfy, how nil
values are disambiguated, and every place where a shipped optic knowingly
deviates from the laws. Randomized law tests in
~test/looking-glass-core-test.el~ exercise the expectations below.

* Law expectations

- Iso :: ~(backward (forward s)) = s~ and ~(forward (backward a)) = a~.
- Lens :: get-set ~(lg-set l (lg-view l s) s) = s~; set-get
  ~(lg-view l (lg-set l a s)) = a~; set-set
  ~(lg-set l b (lg-set l a s)) = (lg-set l b s)~.
- Prism :: ~(lg-preview p (lg-review p b)) = (lg-just b)~, and when
  ~(lg-preview p s) = (lg-just a)~ then ~(lg-review p a) = s~.
- Affine traversal :: lens laws restricted to the present-focus case;
  absent focus leaves the source unchanged.
- Traversal :: identity ~(lg-over t #'identity s) = s~; composition of
  successive ~lg-over~ calls fuses.
- Indexed optics :: same as the unindexed law of the underlying kind;
  indices are metadata and never change which focuses are visited or
  their order.

* Nil disambiguation

nil is a legal focus value. Anywhere absence must be distinguished from a
present nil, tagged Maybe values are used: ~lg-nothing~ and
~(lg-just . VALUE)~ (constructed with ~lg-just~). ~lg-preview~ returns a
tagged Maybe; ~lg-view~ signals ~lg-no-focus~ instead of returning nil for
"no focus". Keyed optics (~lg-ix~, ~lg-at~) use the same tagging for
membership.

* Documented deviations

- ~lg-slice~ :: a lawful lens only for length-preserving writes. When a
  write changes the list's length, the fixed ~[START, END)~ window no
  longer lines up, so get-set and set-set fail. Insertion support is the
  point of the optic; the deviation is accepted and documented in its
  docstring.
- ~lg-number-string~ :: ~preview~ then ~review~ canonicalizes formatting:
  ~"  -3.5 "~ previews to ~-3.5~ but reviews to ~"-3.5"~; ~"1e3"~ reviews
  to ~"1000.0"~. Lawful up to canonical number formatting.
- ~lg-symbol-string~ :: ~review~ accepts any symbol, but an uninterned
  symbol's name previews to the interned symbol of the same name (or to
  no match), so ~preview (review b) = Just b~ can fail for uninterned
  symbols.
- ~lg-json-parse~ / ~lg-json-parse-with~ :: round-trips are lawful up to
  JSON formatting: whitespace is normalized and numbers are rendered
  canonically (~1e2~ becomes ~100.0~). Configurations whose value
  representations cannot round-trip at all (alist/plist objects with
  list arrays; list-shaped containers with a nil null object) are
  rejected at construction time.
- ~lg-utf8~ :: preview succeeds only for unibyte strings that decode to
  UTF-8 text containing no raw-byte characters and re-encode to the same
  bytes. Within that domain both prism laws hold, including for
  pure-ASCII byte strings.
- ~lg-at~ on plists/alists with duplicate keys :: deletion removes every
  binding of the key (so get-after-delete is ~lg-nothing~, as the at-lens
  law requires), but updates rewrite only the first binding — which is
  the one reads see, so get-set and set-get hold. Shadowed duplicates are
  preserved by updates.
- ~lg-getter~ :: setter-like operations through a getter leave the source
  unchanged (a documented no-op), whereas viewing through a pure review
  (~lg-unto~) signals. The asymmetry is deliberate: getters are usable
  inside larger compositions where a write elsewhere is meaningful, while
  a review has no source to read.
- Indexed composition :: ~lg-compose-indexed~ threads the enclosing index
  inward; optics that generate their own indices replace it, so the
  innermost index wins. Use ~lg-icompose-with~ to combine outer and inner
  indices instead.
- ~lg-unmaybe~ :: intentionally lossy adapter; see its docstring.
